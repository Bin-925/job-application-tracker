## 재생성

`reader.css`, `reader.js`, `build-study.mjs`는 읽기용 HTML을 생성하는 문서 전용 파일입니다. 애플리케이션의 프론트엔드 빌드와 관계없습니다.

Node.js와 Marked 17.0.5를 사용할 수 있는 환경에서:

```powershell
$env:MARKED_MODULE = 'C:\도구경로\node_modules\marked\lib\marked.esm.js'
node build-study.mjs
```

`MARKED_MODULE`을 생략하면 현재 작성 환경의 Codex 번들 런타임 경로를 사용합니다. 생성기는 장·다이어그램 수와 로컬 소스 링크의 파일 존재 여부를 출력합니다. 읽기만 할 때는 Node나 Marked 설치가 필요하지 않습니다.
