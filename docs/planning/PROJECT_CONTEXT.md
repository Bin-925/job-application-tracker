취준노트는 여러 회사에 지원하는 구직자가 지원 현황과 일정을 한곳에서 관리하는 서비스다. 본인의 실제 구직 활동을 지원하면서 개발 역량을 보여주는 것이 출발점이다.

아래는 최초 ZIP 검토 당시의 상태다. 현재 구현은 위 개발 재개 위치의 문서를 우선한다.

최초 핵심 모델은 `Member`와 회원에 속한 `Application`이었다. 회사, 직무, 진행 상태, 지원일, 마감일, 면접일/시간, 링크, 메모를 저장했다. 최초 버전은 하나의 지원 건에 하나의 면접 일정만 저장했으며, 현재는 복수 일정 모델을 구현했다.

Java 21 / Spring Boot 3.5.15 / Spring Security / JWT / JPA 백엔드와 JavaScript / React 19 / Vite / Tailwind 프론트엔드가 있다. 운영 PostgreSQL, 로컬 MySQL, 테스트 H2 구성이다. GitHub Actions는 백엔드 테스트를 실행하도록 정의돼 있다.

지원 CRUD, 소유권 검사, 상태 변경, 목록 필터/검색/정렬, 캘린더, 통계, 계정 관리 코드가 있다. 현재 알림은 브라우저에서 3일 이내 일정을 계산하는 인앱 목록이다. PWA, 백그라운드 푸시, Android 패키지, 채용 API 연동은 이 사본에서 확인되지 않는다.

[상세 구현 설계](IMPLEMENTATION_DESIGN.md)와 [구현 순서 및 완료 기준](IMPLEMENTATION_ROADMAP.md)이 구체화된 최신 제안이다. 아래 초기 발전 전략보다 우선해서 읽는다. 주요 제안은 기존 React/Spring 유지, PostgreSQL 통일, 브라우저 PWA/TWA에 맞춘 같은 origin 서버 세션, 복수 일정 모델, DB 기반 알림 작업, TWA 우선 출시다. 현재 JWT를 이미 교체한 것은 아니며 모든 구현 선택은 설계 제안 상태다.

[발전 전략](DEVELOPMENT_STRATEGY.md)은 코드와 공식 문서를 바탕으로 한 제안이며, 모든 기술 도입이 확정된 것은 아니다.

권장 순서는 실사용 신뢰성 확보 -> PWA 설치/조회 경험 -> 일정 알림 신뢰성 -> 원스토어 앱 출시다. 백엔드는 현재 단일 Spring 애플리케이션을 유지하고, Android 구현 방식은 PWA 검증 후 TWA와 Capacitor를 비교한다.
